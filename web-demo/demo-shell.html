Little Hands — working MVP demo

The mobile app’s screens, running in a browser on the same engine code that ships in the repo: the bundle below is @littlehands/core compiled as-is — real tracing corridors, puzzle snapping, reward caps, screen-time ledger and parental gate.

Onboarding
Placeholder art (emoji) and silent audio are stand-ins labelled illustrative in the repo — production illustrations and recorded voice arrive via the CMS workflow (docs/12). Spoken labels here use your browser’s speech synthesis as a stand-in for the recorded child-friendly voice. Data persists in this page’s local storage only; Parent → Privacy & Data → Delete runs the app’s real one-shot deletion and verification path. Tip: set the screen-time target to “1 minute (demo)” in Parent → Screen time to see the calm end-of-day flow.
